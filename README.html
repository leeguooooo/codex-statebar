Codex Statebar

为 Codex CLI 提供配额、上下文、模型、推理强度、Git、活动、预测和多主题状态栏。

数据直接来自本地 $CODEX_HOME/sessions/**/rollout-*.jsonl；不会读取 auth.json，不会上传 session 内容。

安装

curl -fsSL https://raw.githubusercontent.com/leeguooooo/codex-statebar/main/install.sh | sh
cxs doctor

发布物由 GitHub Actions 构建为独立二进制；用户端不需要 Python。

使用

目标命令
显示当前状态cxs
实时独立面板cxs watch
诊断数据与接入cxs doctor
主题 / 样式预览cxs preview
切换主题cxs config set theme nord
切换样式cxs config set style capsule
配置 Codex 原生降级栏cxs --setup
JSON 输出cxs --json-output

Codex TUI 接入边界

稳定版 Codex 支持 [tui].status_line 内置字段列表，但目前没有 Claude Code 那种“执行外部命令并渲染 stdout”的扩展点。因此 cxs --setup 只配置原生降级字段，不会伪装成富状态栏已嵌入。

完整富渲染当前可用于直接命令、watch、tmux / shell prompt，以及提供外部状态命令 hook 的 Codex 补丁版或未来版本。相关上游请求见 openai/codex#17827。
