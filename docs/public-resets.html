Codex 官方重置状态与语言适配

Codex Statebar 通过 Codex Resets 公开 API 显示官方重置公告。它不代表当前账户已到账，也不会修改个人 5 小时或每周额度。

状态含义

API 字段显示示例判断规则
latest_reset官方重置 · 8小时前
储备重置 · 8小时前		依据 announced_at 计算距公告的时间；regular 是常规重置，banked 是储备重置额度。
scheduled_reset已公告重置 · 2小时后
已公告重置 · 等待确认		scheduled_for 有未来时间时显示倒计时。无准确时间、或时间已到，均等待执行确认，不能自动视为完成。
active_watchAI 预测 · 可能重置 (75%)只在 observed_at 至 expires_at 之间显示。概率是站点的 AI 分类结果，不是 OpenAI 承诺；不把 forecast_window 自由文本解释为精确时间。

已公告状态优先于 AI 预测；最近完成记录可以同时显示。历史平均间隔不用于推算下一次重置。

语言与配置

新增的重置文案支持简体中文、繁体中文、英语、日语、韩语。lang auto 在 macOS 上跟随 AppleLanguages 首选语言，其他平台依次读取 LC_ALL、LC_MESSAGES、LANG；未支持语言回退英语。原有界面中尚未翻译的文案仍使用原来的回退方式。

cxs config set lang auto
cxs config set lang zh
cxs config set lang zh-TW
cxs config set lang en
cxs config set lang ja
cxs config set lang ko
cxs config set show_resets false

默认开启，关闭后停止该功能的后台刷新。无额度的 API/中转模式隐藏此行。首次使用等待后台请求完成后显示。

刷新与失效

渲染只读本地缓存。后台每 5 分钟最多请求一次 GET /api/v1/status，使用 ETag 条件请求和独占标记去重。请求超时为 6 秒，响应上限 1 MiB。429 的 Retry-After 秒数在 5 分钟至 24 小时范围内生效。失败时保留上次有效数据；超过 5 分钟标注缓存，超过 1 小时隐藏。过期预测即使缓存尚在也不显示。
